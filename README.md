# Zero Track Blog

Original security research, writeups and engineering notes from Zero Track Lab.
Verified work only — every claim ties to a checkable record.

**Live:** https://tawffik.github.io/blog/

## Structure
- `posts-md/` — markdown sources (canonical; also mirrored in the research writeups of `Tawffik/web-api-pentest-portfolio`)
- `posts/` — rendered post pages (generated, committed)
- `index.html`, `feed.xml`, `sitemap.xml` — generated by `build.py`
- `static/` — design system (self-hosted IBM Plex fonts, zero external requests)

## Add a post
1. Drop `YYYY-MM-DD-slug.md` into `posts-md/` (first line `# Title`, second line blank,
   third line an italic meta strip `*Published ... · Labels: ...*`).
2. Run `python3 build.py` (needs pandoc).
3. Commit + push; GitHub Pages serves `main` from `/`.

## Custom domain (later)
When the domain is purchased: add a `CNAME` file with the bare domain, set it in
repo Settings → Pages → Custom domain, and update `BASE` in `build.py` before rebuilding.
